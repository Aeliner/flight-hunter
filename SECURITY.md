# Security policy

Please report vulnerabilities privately through GitHub: **Security → Report a vulnerability** on https://github.com/Aeliner/flight-hunter. Don't open a public issue for them.

Expect a first reply within 7 days. Fixes ship as a new plugin version; bump notes are in the release tags.

In scope: the plugin's scripts, MCP server (`skills/hunt/scripts/apis_mcp.py`), manifests and skill instructions. Bugs in third-party services (Google Flights, Kiwi, Kayak, fli, api-anything) belong with those projects.
